# SpacePrune 社区行为准则

## 目标

SpacePrune 致力于提供友善、专业且不受骚扰的协作环境。所有参与者无论经验、身份、背景或参与方式，都应得到尊重。

## 适用范围

本准则适用于项目仓库、issue、代码评审、讨论区、发布渠道，以及参与者代表 SpacePrune 进行的公开交流。

## 期望行为

- 尊重不同观点、经验和语言能力；
- 对代码和事实提出具体、可执行的反馈，不攻击个人；
- 主动说明假设、风险和验证边界；
- 接受合理的维护决定，并通过正常评审流程提出异议；
- 谨慎处理他人的个人信息、安全报告和未公开资料。

## 不可接受的行为

- 歧视、侮辱、威胁、骚扰、跟踪或不受欢迎的性关注；
- 公开他人的私人信息，或诱导他人泄露凭据和敏感内容；
- 持续的人身攻击、恶意挑衅、刷屏或蓄意破坏协作；
- 冒充项目成员，或以项目名义作出未经授权的承诺；
- 维护者合理判断为不安全、不专业或明显妨碍社区参与的其他行为。

## 报告与保密

行为问题应通过规范仓库托管平台提供的私密联系或举报功能提交给维护者。不要在公开 issue 中放入个人信息、
安全细节或可能造成进一步伤害的材料。维护者只会在处理所必需的范围内共享报告；被报告人是维护者时，应由
未涉及该事件的维护者处理。

安全漏洞不属于本准则的普通行为报告范围，应遵循项目发布的 `SECURITY.md`。在正式安全渠道尚未配置前，
不要公开披露可利用细节。

## 执行

维护者可根据行为的严重程度和持续性采取内容编辑或删除、私下提醒、正式警告、临时限制参与或永久移除等措施。
处理决定应说明被违反的规则，避免利益冲突，并尽可能保护报告者和受影响者的隐私。

对处理决定有异议时，可通过同一私密渠道请求由未参与原决定的维护者复核。善意报告不会因最终未能证实而受到处分；
故意虚假或报复性报告本身可能违反本准则。
